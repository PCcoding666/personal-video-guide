# Daily digest

This mode is not finished in the toolkit. `sources.json` is not stored yet, and there is no `digest.record` tool. Do not pretend a video was marked as already recommended.

Until that exists, a "what's new" request is a manual watch-along over URLs the user just gave you:

1. Confirm the channels with the user.
2. For each URL they want considered, run the watch-along flow in [watch-along.md](watch-along.md).
3. Recommend at most a few segments, with a reason and evidence, and let them choose.

When the host can schedule, the user has to agree to the time first. The toolkit will not send a notification. If the host was closed at that time, say that the next open is when the digest can run.
